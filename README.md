# Custom Kodi Add-ons Repository

Welcome to my personal repository of custom-built, high-performance Kodi video add-ons. Designed for **Kodi v21 (Omega)** and above, these add-ons are built from the ground up to provide a lightning-fast, premium streaming experience with beautiful metadata integration.

---

## 🎬 Available Add-ons

### 🍿 MovieBox
The flagship video add-on for streaming movies and TV shows.
*   **Features:** Full TMDB metadata integration, beautiful fanart/posters, and seamless playback using Kodi's native player.
*   **Version:** 1.0.0

### 🔴 NetflixMirror
A sleek, Netflix-inspired streaming add-on.

*   **Version:** 1.0.0

### ⛩️ HiAnime
The ultimate anime streaming experience directly inside Kodi.

### 🎞️ HDHub4u
A robust, lightweight streaming add-on for the latest movies and shows.

## 🚀 Key Features
- **Native Player Integration:** Utilizes Kodi's built-in FFmpeg player and InputStream Adaptive for smooth, hardware-accelerated playback.
- **Rich Metadata:** Full integration with TMDB API to pull high-res posters, fanart, cast lists, plots, and ratings.
- **Fast Scraping:** Custom-built Python scrapers that load source links instantly without bloated dependencies.
- **Clean UI:** No unnecessary menus or clutter. Just beautifully categorized content ready to watch.

## 📦 Installation Guide

You can install any of these add-ons manually via their `.zip` files:

1. **Download the Add-on:**
   * Download the `.zip` file for the add-on you want from the files list above (e.g., `plugin.video.moviebox.zip`).
2. **Open Kodi:**
   * Navigate to **Settings** (the gear icon) > **Add-ons**.
3. **Install from Zip:**
   * Select **Install from zip file**.
   * If prompted, enable "Unknown sources" in your Kodi settings.
   * Navigate to where you downloaded the `.zip` file on your device and select it.
4. **Enjoy:**
   * Once installed, you will see a notification in the top right corner. The add-on is now available in your **Video Add-ons** menu!
